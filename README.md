# R_blmaster

Blender 4.2+ 中文扩展，作者 **ERDCX**，GPL-3.0-or-later。v1.0.0 起由 MaterialFX Suite 更名为 R_blmaster：材质、特效与模型 CAD 工具合并到侧边栏同一个 **R_blmaster** 标签页中，减少侧边栏占用。

## 安装

**重要：本版本更换了扩展 ID（materialfx_suite → r_blmaster），升级前必须先在偏好设置中移除旧版 MaterialFX Suite（0.9.x），再安装本包**，否则两个版本会并存。

在 Blender 4.2 中打开 **编辑 > 偏好设置 > 获取扩展 > 从磁盘安装**，选择 `R_blmaster_v1.0.6.zip`。压缩包根目录包含扩展清单、Python 实现、`previews` 材质球预览图、`textures` 内置贴图和本说明。安装后在 3D 视图按 `N`，打开 **R_blmaster** 标签（材质、特效、模型 CAD 三个面板；材质页拆为「预设库 / PS 材质图层编辑 / 预设管理与分享 / 贴图与烘焙」四个可折叠子面板，特效页拆为「雷电 / 表面 / 几何 / 消散碎裂 / 音频 / 体积特效」六个子面板，模型 CAD 页支持 GLB / FBX / USD 场景导出）。作者署名放在面板底部的小字和插件元数据中。旧场景中的特效层/材质层数据完全兼容，无需迁移。

## 参数实时调节与双向联动（v1.0.5 起）

- **拖动即生效**：创建面板上的调节参数（材质图层、雷电、表面特效、几何特效、消散碎裂、音频增益、体积雾、雨雪、烟雾、火焰、液体等）在已添加的特效上**拖动滑块当场变化**，不需要删除重加、也不需要点确认——参数同时还是下次创建的默认值。
- **两处调节永远一致**：图层堆栈/特效层堆栈里的参数与创建面板参数**双向实时联动**——在堆栈里改，面板读数跟着走；在面板里拖，选中层当场生效。同一特效两处看到的值恒等。
- **切换即跟随**：点选堆栈中某一层，面板自动切换到该层当前参数，无残留旧值。
- **结构类参数例外**：改变拓扑或随机性的参数（电弧数量、分支层级、随机种子、碎片数量、雨雪类型切换、液体初始状态、音频采样间隔等）标注「重新添加特效后生效」——这类参数无法在已建特效上原地热改，属 Blender 引擎机制。
- **真实模拟自动重烘焙**：烟雾/火焰/液体的分辨率、时长改动后，旧缓存自动失效，约 1 秒后**自动开始重烘焙**（后台进行不冻结界面），体积特效面板底部状态行实时显示「失效 → 烘焙中 → 已就绪」。大分辨率 + 长时长烘焙耗时较长，是 Mantaflow 引擎算力所致；正式出图建议烘焙后离线渲染。

## 材质

- 120 个预设选择器缩略图均为对应程序化材质的球体渲染，含钢铁、黄铜、铝、紫铜、青铜绿锈、镀锌钢、塑料、橡胶、亚克力、碳纤维、混凝土、砖、砂岩、抹灰墙、大理石、沥青、木材、清漆木面、竹材、玻璃、磨砂玻璃、陶瓷、赤陶土、皮革、织物、丝绸、苔藓、土壤、沙、雪、冰、水、树皮和植被等现实材质及明暗变体。支持分类、搜索、收藏与最近使用。
- 40 种程序化材质模板（复用 28 种程序化节点结构）：拉丝金属的定向纹、锈蚀/混凝土的斑驳色层、砖块与砂浆、花岗岩颗粒、木纹、皮革毛孔、织物纤维、苔藓团簇、土壤/沙粒、雪冰、水体、树皮纹理、玻璃传输和陶瓷涂层等。
- 8 套内置照片级贴图材质（Poly Haven CC0，1k 三通道：基础色/法线/粗糙度）：砖墙、混凝土墙、木地板、柏油路、锈蚀金属、碎石地面、牛仔布、瓷砖地面；每套都有使用对应 PBR 贴图渲染的材质球预览。本地加载断网可用，可再叠材质图层与特效做风化、积灰等做旧组合。贴图材质建议物体先做 UV 展开（未展开时按包围盒投影）。
- 每个材质最多添加 8 层，支持噪声、AO、法线朝向、高度、物体坐标、渐变、波纹、顶部积灰、底部磨损、同心环、棋盘格、Voronoi 斑块和 Cycles 曲率共 13 种智能遮罩；高度、渐变、顶部积灰与底部磨损可点选 ±X/±Y/±Z 六个方向。提供 18 种 Photoshop 风格颜色混合模式（包括线性减淡），另有遮罩式正常混合与发光叠加。图层堆栈按 PS 逻辑显示：上层在上，可逐层隐藏、调不透明度、调整顺序和删除；选中层后颜色、粗糙度、遮罩、花纹密度和混合模式针对该层生效。颜色和数值拖动只更新当前节点，不会反复重建整条图层链。不同材质的图层互不计入对方的 8 层上限；无效记录可单独清理。
- 支持应用到所选物体、活动集合或整个场景，随机材质分配、当前材质标记为 Blender 资产，以及 JSON / `.blend` 材质预设导入导出。
- PBR 目录自动识别 BaseColor、Roughness、Metallic、Normal、Height、AO 和 Emissive 通道，支持 UDIM 命名；导入图像自动使用按表面法线选面的 Box 三向投影，无需 UV。
- **程序化纹理投影（全局三选项）**：「生成坐标」（默认 · 与旧版一致——纹理贴合物体表面，随物体变换；非立方体物件侧面密度可能不均）、「物体坐标」（按物体尺寸适配——纹理跟随物体移动 / 旋转）、「世界坐标 · 推荐」（按场景实际尺寸 · 侧面不挤压——纹理锚定场景，物体移动 / 旋转不跟随）。切换后全部托管材质立即重连生效，重放期间窗口底栏显示进度，完成后无弹窗；开文件 / 点击已选项零重放，默认值与旧版逐链接一致（老场景零漂移）。旧版本创建的托管材质自动识别参与切换；PBR 图片链、遮罩链与三向投影文案不受影响。
- Cycles Base Color 烘焙；若网格没有 UV，会先自动智能展开。支持导出选中物体为 GLB、FBX 或 USD（已移至「模型 / CAD」页）。

## 模型 / CAD

- 可导入 STL、**分面 STEP/STP**、FBX、OBJ、PLY、glTF、USD 和 Alembic 网格模型。支持本插件导出的分面 B-rep STEP（含带洞平面）与同类分面实体；Fusion 360 导出的参数化 B-rep（NURBS 曲面）STEP 不在支持范围，导入时会明确提示改用网格导出（STL/OBJ）。
- 四边面重拓扑三级通道：① 检测到已安装的 **Exoside QuadRemesher**（正版商业插件）时自动出现「用 Exoside 引擎重构」按钮，质量最佳；② 内置 **Quadriflow** 通道，v1.0.0 起执行前自动清洗网格（焊重合点、删游离几何、重算法线），并以后台轮询确认真实完成——引擎失败会明确报错并清理副本，不再出现"显示成功但模型没变"；③ 两通道都会保留原模型，结果生成独立副本。
- 可将选中网格导出为 STL、FBX、OBJ、GLB 或 STEP。STEP 导出会直接把封闭网格写成 AP203 分面 B-rep 实体，可在 Fusion 直接打开并编辑面、边；非封闭/非流形网格须先修复，每个对象限一个连续壳体，每次最多 60,000 个面。
- **共面融合（默认开启）**：导出 STEP 时把同一平面上的相邻三角面融合为整面——Fusion 360 中同一平面只有一个面、没有内部切割线，选中/编辑面更顺手。判定角度可在面板调节（默认 0.5°）；融合只改导出副本的拓扑组织，不影响原模型几何。个别复杂区域会自动回退为逐三角面以保证文件合法。
- **退化面自动清理（v1.0.5）**：导出前自动清理网格里的零长度边、零面积面与游离元素并在完成提示中汇报数量——含零面积面的模型不再触发「面积为零」塌缩报错；导出目录不可用（如盘符失效）时报统一错误提示而不是崩溃。
- STEP 是分面实体，不会从网格恢复草图、尺寸约束或参数化 CAD 特征树。高面数模型建议先重拓扑减面，再导出 STEP。

## 其他工具

- 效果动画层可以设置曲线缓动和无循环、循环、镜像、偏移循环；音频驱动可从 PCM WAV 写入发光强度关键帧。
- Cycles 烘焙可选择 CPU 或已启用的 GPU。团队材质包 `.mfxpack` 附带 `.blend` 材质和自动渲染的材质球预览，可导入、导出及在团队预设分类中预览。
- EEVEE 的曲率遮罩使用环境遮蔽近似，Cycles 使用 Pointiness。火焰/烟雾、冰霜、故障与腐蚀是程序化表面着色器效果；冰霜与腐蚀带方向性动画，不是体积或真实物理蔓延模拟。几何粒子是表面实例，不带碰撞模拟。Voronoi 切割封口效果取决于输入网格是否封闭且拓扑有效。

建议贴图后缀：`_BaseColor`、`_Roughness`、`_Metallic`、`_Normal`/`_NRM`、`_Height`、`_AO`、`_Emissive`。UDIM 文件名示例：`Robot_BaseColor.1001.png`、`Robot_BaseColor.1002.png`。

## 特效

- 雷电生成独立发光曲线对象，支持空间、表面、定向模式；颜色、强度、线宽与持续帧数拖动即时生效（已生成的闪电当场变化），电弧数量、分支数量与层级、抖动、随机种子等结构参数标注「重新添加特效后生效」；随机脉冲在设定时长内闪烁。
- 消散效果复制当前材质，使用噪声边缘并添加进度关键帧；持续帧数拖动即时重排动画。
- 能量流在材质上叠加扫描线，并沿坐标方向动画；流动时长拖动即时重排动画。
- 碎裂重组按 Voronoi 半空间对网格执行实际切割并封闭切面，生成可编辑独立碎片，添加飞散/回位关键帧；飞散距离、持续帧数与统一起始帧拖动即时生效，碎片数量与随机种子为结构参数（重新添加生效）；支持固定随机种子和恢复源物体。
- 所有内置动画可设置统一起始帧（默认跟随当前帧），改动后全部已建特效动画整体平移；消散、能量流与碎裂分别设置持续帧数。
- 额外的表面特效包括全息扫描、四维噪声故障闪烁、火焰/烟雾程序扰动、冰霜晶格、锈蚀色层、自发光脉冲、独立轮廓光外壳与 EEVEE 卡通分阶着色；颜色与强度拖动即时生效（卡通/轮廓/火焰坡道同步更新），特效类型与方向为结构参数（重新添加生效）。
- **体积特效（含「自然（默认）/±X/±Y/±Z/自定义角度」方向体系，默认零偏置；本块全部调节参数拖动即时生效）**：
  - 程序化（免烘焙）：体积雾——包裹选中物体，密度 / 颜色 / 形态规模 / 流动开关 / 方向全部即时可调，改方向或关掉流动动画后流动关键帧自动重写；
  - 天气粒子：雨 / 雪按选中物体尺寸自动覆盖，数量、覆盖范围、风偏角度拖动即时生效（雨雪类型切换为结构参数，重新添加生效；雨丝重力加速、雪花慢速飘落）；
  - 真实模拟（Mantaflow 引擎）：烟雾（颜色 / 密度即时可调）、火焰（橙红 / 蓝焰色温与强度即时可调，风偏实时更新、浮力项不动保持自然升腾）、液体（液体颜色即时可调，初始状态为结构参数）；分辨率 32/64/128 与时长改动后自动失效旧缓存并自动重烘焙（后台进行，面板底部状态行显示进度）；缓存统一写 `//mfx_cache/`（删除特效层即删域对象，缓存目录需手动清理）。
- 特效层堆栈可单独启停、用滑杆实时调节强度和删除，且与创建面板参数双向联动（堆栈改 → 面板读数跟随；面板改 → 选中层当场生效）；材质动画会按各层初始曲线比例更新，几何节点层会同步更新修改器与动画关键帧。删除会旁路材质效果或清理其几何节点、碎片和特效对象。发光叠加类效果可选择直接叠加或与底材混合。支持非破坏式 Geometry Nodes 波浪/旗帜位移、高度生长显露、方向可选的生长/波动，以及保留原模型、可调大小和密度的表面粒子散布与消散动画。

## 验证

已在 Blender 4.2.22 LTS 的 factory-startup 隔离场景验证材质与特效基础操作、音频 WAV 驱动、循环动画、团队材质包预览生成/导入导出、模型导入导出、不同目标面数下的 Quadriflow 副本重拓扑，以及封闭立方体 STEP 生成和开口网格拦截。STEP 文件检查了实体/面数量、头尾标记和实体引用完整性。验证不会载入、保存或覆盖用户的 `.blend` 文件。不同网格和渲染设备会影响实际效果；GPU 烘焙需有兼容且在 Blender 中启用的设备。

### 当前限制

STEP 导出要求封闭、流形、单一连续壳体网格；开口面、非流形边和多个互不相连壳体需先修复或拆成独立对象，导出上限为每次 60,000 个三角面。导出的 STEP 采用分面 B-rep，可编辑几何面和边，但不会重建参数化 CAD 特征树。Blender 本身没有 STEP 导入器，导入 STEP 前需在 Fusion 中另存为 STL/OBJ。Quadriflow 是重新生成拓扑，不保证保留源网格上的所有细节；需要更高保真时可提高目标面数。贴图材质优先使用 UV，未展开网格使用包围盒投影。应用效果会创建独立材质、对象、修改器或关键帧，用户可在 Blender 中继续编辑。
